# Junior Golf School Matching Platform


## Project Overview
A web application designed to help junior golfers identify high schools and universities that match their academic, athletic, geographic, and financial preferences.


## Target Users
Junior golfers exploring school opportunities.


## Planned MVP
- User preference questionnaire
- School database
- School matching
- Match results
- School details
- School comparison
